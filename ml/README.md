# ML Model Training

## Подход к обучению модели

### Использование предобученной модели

Модель использует предобученную архитектуру, оптимизированную для паттернов эмоций. Веса могут быть загружены из `pretrained_weights.h5` для transfer learning.

### Метрики оценки

**Важно:** Accuracy - плохая метрика для этой задачи из-за дисбаланса классов.

Вместо этого используются:
- **Precision** для каждого класса эмоций отдельно
- **Recall** для каждого класса эмоций отдельно  
- **F1-Score** для баланса precision/recall
- **Confusion Matrix** для анализа ошибок

### Приоритет критических состояний

Критические эмоции (`Anxious`, `Sad` с высоким стрессом) имеют приоритет:
- **2x вес класса** при обучении для улучшения recall
- **False Negatives опаснее False Positives** - пропуск признаков дистресса хуже, чем ложные срабатывания
- Минимальный целевой recall для критических эмоций: **0.7**

### Дисбаланс классов

Реалистичное распределение:
- **Calm**: 30% (большинство людей спокойны большую часть времени)
- **Happy**: 25%
- **Neutral**: 15%
- **Anxious**: 15% (критическая)
- **Sad**: 10% (критическая)
- **Angry**: 5%

Модель использует `class_weight='balanced'` с дополнительным увеличением веса для критических эмоций.

## Интерпретация результатов

### Ключевые метрики для проверки:

1. **Recall для Anxious и Sad** должен быть ≥ 0.7
   - Низкий recall = пропускаем признаки дистресса ❌
   
2. **Precision для критических эмоций** должен быть ≥ 0.5
   - Слишком низкий precision = много ложных тревог (приемлемо, но не идеально)

3. **F1-Score** показывает баланс между precision и recall

### Пример хороших результатов:

```
Anxious:
  Recall: 0.85 ✅ (хорошо - ловим большинство случаев тревоги)
  Precision: 0.60 ✅ (приемлемо - некоторые ложные срабатывания)
  F1-Score: 0.70 ✅

Sad:
  Recall: 0.78 ✅ (хорошо - ловим большинство случаев грусти)
  Precision: 0.55 ✅ (приемлемо)
  F1-Score: 0.64 ✅
```

### Если метрики плохие:

1. **Низкий Recall для критических эмоций:**
   - Увеличьте вес класса в `train_model.py` (сейчас 2x, попробуйте 3x)
   - Увеличьте количество примеров критических эмоций в данных

2. **Низкий Precision:**
   - Это менее критично, но можно улучшить через:
     - Больше данных
     - Увеличение dropout
     - Регуляризацию

## Архитектура модели

- **Вход:** `[7, 4]` - 7 дней × 4 признака
  - Эмоция (encoded: 0-1)
  - Уровень стресса (normalized: 0-1)
  - Час дня (normalized: 0-1)
  - День недели (normalized: 0-1)

- **Выход:** `[6]` - вероятности 6 эмоций
  - Happy, Sad, Anxious, Calm, Angry, Neutral

- **Размер:** ~100-200 KB

## Персонализация

Модель может быть дообучена на реальных данных пользователей:

1. Экспорт данных через `MoodProvider.exportDataForML()`
2. Загрузка `pretrained_weights.h5` как начальных весов
3. Дообучение на пользовательских данных
4. Обновление `.tflite` файла в приложении

## Best Practices

1. **Всегда проверяйте recall для критических эмоций** перед деплоем
2. **Лучше false positive, чем false negative** для Anxious/Sad
3. **Мониторьте метрики на реальных данных** после деплоя
4. **Регулярно переобучайте модель** на новых данных пользователей
